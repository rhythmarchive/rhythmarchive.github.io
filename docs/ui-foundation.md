# Public UI 基础

网站保留蓝色与青色强调、浅色档案背景、深色主题和以资源图片为主的卡片展示。首页、资源列表、详情和剧情地图具有不同的信息密度，不要求使用同一种布局。

## 样式入口与复用

- `apps/site/src/styles/global.css` 管理主题、字体与动效变量、页面容器、标题、通用字段、按钮、筛选、卡片和状态面板。
- `motion.css` 管理交互与动效层（浮层进出、列表反馈、按压、加载占位）；`experience.css` 管理品牌标记、首页构图、卡片悬浮层、指针效果、区间分布图和不可选中控件列表。两者在 `BaseLayout` 中按 global → 专用样式 → motion → experience 的顺序加载。
- `local-library.css`、`media-gallery.css` 只管理收藏与媒体视图的专用布局；普通控件复用全局规格。
- 资源卡片继续使用现有 `CardShell.astro`、`card-view-model.ts` 和 `render-resource-card.ts`，分别覆盖静态与动态渲染，不另建卡片实现。
- 剧情地图的深色画布、节点形状与摄影机控件保留在 `story-atlas.css`。其游戏内视觉语义不套用普通资源列表的样式。

## 视觉与布局规格

| 用途 | 现有入口与规格 |
| --- | --- |
| 页面宽度 | `.page-container`，最大 1320px，桌面两侧 24px，600px 以下两侧 14px |
| 列表页标题 | `.page-heading`，共用 `--page-title` 与 `--page-head-space`；搜索居中、反馈页装饰和更新详情宽度由页面保留 |
| 正文与辅助信息 | `--text`、`--text-muted`、`--text-soft`，使用主题变量，不另写局部灰色 |
| 圆角 | `--radius-sm: 9px` 用于控件与缩略图；`--radius-md: 14px` 用于卡片与媒体画布；`--radius-lg: 20px` 用于浮层 |
| 原生输入与选择框 | `--control-height: 40px`，600px 以下 44px；同一背景、边框、内边距与焦点规格 |
| 密集切换按钮 | `--control-compact: 36px`，600px 以下 44px；沿用现有按钮组和标签形状 |
| 选中状态 | `--control-selected` 与 `--accent-strong`；语义使用 `aria-selected`、`aria-pressed` 或 `aria-current` |
| 键盘焦点 | `--focus-ring`，3px 描边；搜索框使用同色外环，专用地图继续使用画布焦点样式 |
| 空状态 | 搜索、收藏、更新共用面板边界、背景、间距；对齐方式与恢复动作按场景保留 |

页面标题可在原有容器添加 `.page-heading`，不必为不同标题创建新的组件。通用字段的共享选择器列出真实使用者；新增使用者应加入现有规则，页面自己的 CSS 仅保留宽度、布局等差异。

## 交互与响应式

原生 `button`、`select`、`details` 优先。链接负责导航，按钮负责操作。禁用按钮不呈现可点击的悬浮抬升；禁用与加载状态不能仅靠鼠标指针区分。资源卡片的键盘焦点与鼠标悬浮共享边界反馈。

所有页面通过 `BaseLayout` 提供“跳到主要内容”。分类导航标注当前页。标签页继续复用已有键盘与 ARIA 实现，不为视觉统一另建交互逻辑。

移动端保留横向分类导航、折叠筛选、两列资源卡片和底部批量工具栏。筛选标签可换行，长标题可断行；根容器不再强制 320px 最小宽度，避免 320px 视口存在滚动条时裁切右侧内容。图片、视频和地图可以有各自的内容布局，普通控件仍遵守共享规格。

视觉基础不增加客户端依赖、全局脚本或额外网络请求。验证 UI 时覆盖桌面、平板和窄屏，以及浅色、深色、焦点、选中和空状态；业务验证沿用现有相关测试。

## 动效与过渡

标准档共用 `--motion-fast: 140ms`、`--motion-ui: 200ms`、`--motion-surface: 280ms`、`--motion-ease: cubic-bezier(.22, 1, .36, 1)`，另有 `--motion-spring`、`--motion-exit-ease` 与位移变量；丰富档和精简档在 `:root[data-motion-level]` 上覆盖这些值。普通反馈最快，页面过渡其次，浮层稍长；交互结果立即更新，不等待动画。档位语义与共享机制见 [site-design.md](site-design.md#motion-system)。

| 场景 | 行为与边界 |
| --- | --- |
| 页面导航 | Astro ClientRouter 在当前文档内切换静态页面，保留页头节点，只淡化主要内容；不预取页面或邻图。不支持 View Transition 时仍用客户端切换，无 JavaScript 时保留独立页面链接 |
| 图片详情 | 只对实际加载的可见图片及主动切换的面板短淡化；原图、超分与难度差分仍沿用既有按需加载和错误回退 |
| 大图开合 | 桌面从当前预览几何位置展开并回收，保持图片比例；触屏只淡化。使用已请求的当前图片，不克隆预览或预取邻图 |
| 浮层与多选栏 | `motion.ts` 统一显隐；退出期间立即 inert，完成后 hidden。快速反向操作从当前状态继续，旧回调不能隐藏重新打开的浮层 |
| 列表内容 | 排序/筛选用 `captureCards` + `animateCards`，只动可见卡片；筛选标签、批量缩略图用 `reconcileList`，带进入、退出残影与位置过渡。多选使用既有 syncCards，保持卡片节点和焦点 |
| 按钮与下载 | 统一颜色、边界和轻微按压反馈；下载期间 disabled 与 aria-busy。触屏不保留悬浮抬升，选中卡片不位移 |

`prefers-reduced-motion: reduce` 或“精简”档不启用页面过渡，JavaScript 动效直接完成状态更新。只动画 opacity 和 transform，不动画布局尺寸、阴影、滤镜或模糊；悬浮阴影放在伪元素上改 opacity。滚动区域和固定栏不使用 backdrop-filter。唯一常驻循环是首页音符轨道，离屏和悬停时暂停。

页面仍由 Astro 静态生成，客户端导航使用 [Astro ClientRouter](https://docs.astro.build/en/guides/view-transitions/)。页面脚本通过 `page-lifecycle.ts` 在 `astro:page-load` 初始化，在 `astro:before-swap` 中止页面监听、清理计时器、观察器和验证组件。页头持久化，活动导航标记从新页面同步。

图库和搜索沿用 URL 筛选、排序及 `list-navigation.ts` 的列表快照；返回时恢复已加载数量，浏览器遍历优先使用 Astro 保存的滚动位置。连续详情替换当前历史项，Back 回到原列表；大图模式随详情切换保留，支持方向键、按钮和单指水平滑动，不预取相邻原图。原图、超分和视频仍按明确操作加载。

`static-data.ts` 按需复用最多六份公开静态投影及正在进行的请求，失败后可重试；不会全局加载 Catalog，也不缓存动态 Stats/提醒响应。主题和移动菜单绑定在持久化页头，普通页面绑定只活到下一次切换。新增页面脚本需沿用这些生命周期和历史字段，不能清空 `history.state` 的路由信息。

## 待专项评估

移动端剧情图谱的初始相机沿用桌面标定，窄屏可能裁切节点；地图占屏较大且 `touch-action: none` 会接管图内触摸滚动。后续专项评估窄屏初始总览和地图高度，保留现有平移能力。本轮收尾不调整图谱、搜索瀑布流或详情标题位置；展示风格留到第三阶段统一评估。
