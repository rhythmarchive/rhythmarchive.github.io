该基线的完整检查通过，站点测试 119 项、Worker 测试 29 项；产物检查未发现凭据特征或本机用户路径。历史扫描发现旧文档/CSV 中的本机路径，未确认真实 Secret。扫描无法覆盖所有无特征 Token、未取回 ref、不可达对象、Actions 历史日志或外部 Release 文件。

线上观测仅使用低影响 GET/HEAD/OPTIONS：主站和 API health 可读，匿名管理接口返回 401，超量榜单参数返回 400，恶意 Origin 返回 403；ROS 匿名列目录被拒绝。没有线上写入、压力测试、隐藏对象下载或存储写权限试验。Cloudflare/GitHub/ROS 权限、Secrets、账单与完整 ACL 未实时核实；备用 workers.dev 入口因 DNS 错误未验证。

## 风险与后续处理

| 编号 | 基线发现 | 长期意义或代码后续 |
| --- | --- | --- |
| M1 | 匿名 visitorId 可自选，交互事件可人为制造 | 统计是客户端报告的交互次数，不是身份认证或成功下载凭证；关注刷榜和用量 |
| M2 | 原生限流成功后绕过更严格的接口窗口 | 同日定向修正为原生前置拦截加 D1 独立窗口，异常失败关闭；生产绑定需独立核对 |
| C1 | 页面隐藏资源的元数据和对象键仍在公开 Catalog | 隐藏、UUID、哈希不是访问控制；私密资料应在公开边界之外 |
| C2 | Turnstile 仅检查 success，缺少 hostname/action，缺 Secret 时跳过 | 同日定向修正为默认必需，核对全部 claims，缺配置失败关闭；前后端与 widget 需配套 |
| H1 | 更新页生成 HTML 时链接属性未统一转义 | 两处 href 复用 escapeHtml 加固；当时未发现普通访客可控的利用链 |
| H2 | 构建及开发依赖命中安全公告 | 公告严重度不等于本站可达风险；升级需按调用条件及当前锁文件判断 |
| H3 | 页面缺少部分显式响应策略 | CSP、frame 与其他响应策略需匹配 GitHub Pages 托管能力及现有组件 |
| H4 | 第三方脚本与 APK 发布链是供应链信任点 | APK 结构及 SHA-256 校验不能证明 Android 发布者签名 |
| H5 | 匿名 ID 与历史表留存说明可改善 | 平台日志和 D1 数据最小化是不同边界；清理历史数据前需备份确认 |
| H6 | CI 与秘密权限需要平台核对 | environment 名称不证明启用审批；关注最小权限、依赖和 Secret 防误提交 |

原审计没有确认可被匿名访客直接利用的 XSS、管理权限绕过、SQL 注入、任意文件读取、开放代理或凭据泄露。该结论受当时输入链和检查范围限制，不能推广为持续安全保证。

M2/C2 定向回归包括原生与持久限流、窗口与 scope、429 CORS、配置缺失、错误 claims、验证服务异常和不写入提醒；当日 Worker 类型检查及 33 项测试通过，前端类型检查与 6 项提醒测试通过。这些是历史证据，不替代后续代码验证或生产配置检查。
