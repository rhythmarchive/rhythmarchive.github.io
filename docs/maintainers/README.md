# 维护者文档

这里面向拥有生产发布权限的项目维护者。内容可以公开阅读，但贡献者不需要执行这些操作或取得相关凭据。本目录不保存秘密，也不替代私有运维应用的资源清单。

- [内容发布与维护](publishing.md)：日常 Git 流程、检查范围、Pages/Worker 顺序和提醒收尾。
- [Stats Worker 运维](stats-operations.md)：首次创建、D1 迁移、生产配置和自动部署。
- [D1 热路径与用量](d1-usage.md)：查询、去重、缓存和测量边界。
- [安全审计摘要（2026-10-02 至 03）](archive/security-audit-2026-10-03.md)：历史风险及证据限制。
- [流量测量（2026-09-23）](archive/traffic-measurement-2026-09-23.md)：预览图改造的历史测量方法和结果。

历史测量不代表当前生产状态或持续有效的安全保证。配置和发布时，以当前代码、工作流及平台设置为准。第三方开发的入口见[贡献指南](../../CONTRIBUTING.md)，Coding Agent 的执行规则见 [AGENTS.md](../../AGENTS.md)。
