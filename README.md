# Rhythm Archive

Rhythm Archive 是一个面向玩家的音游图片归档与下载网站。网站按游戏和资源类型整理曲绘、角色图片、剧情插画及其他视觉内容，支持搜索、分类浏览、图片预览、原图与高清版本下载，以及资源反馈。

## 本地预览

npm ci
npm run site:dev

构建检查使用 npm run ci:check，本地构建产物可使用 npm run site:preview 查看。

## 网站入口

- 首页：搜索资源并查看最近收录的游戏
- 游戏库：按游戏进入对应资源分类
- 资源库：跨游戏搜索并按分类浏览
- 详情页：查看图片、尺寸、版本和下载选项
- 意见反馈：提交资源错误和使用建议
