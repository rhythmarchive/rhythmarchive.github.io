# Rhythm Archive

**面向音游玩家的图片资源归档与下载站**

本站整理并收录各类音游图片资源，方便搜索、浏览与下载。

[🌐 访问网站](https://rhythmarchive.github.io) · [🔎 搜索资源](https://rhythmarchive.github.io/search/) · [💬 意见反馈](https://rhythmarchive.github.io/feedback/)

</div>

---

## ✨ 关于

Rhythm Archive 按游戏与资源类型整理图片内容，提供统一的浏览和搜索体验。

| | |
| --- | --- |
| 🔎 **搜索** | 跨游戏检索图片资源 |
| 🖼️ **浏览** | 按游戏、分类与元数据浏览 |
| 📥 **下载** | 查看原图及可用的高清版本 |
| 🌙 **体验** | 响应式页面，并支持亮色 / 暗色主题 |

## 📚 收录内容

- 曲绘 / Jacket
- 角色立绘
- 剧情 CG
- 曲包封面
- 背景与其他视觉资源

> 收录内容会随项目整理持续更新。

## 🧭 从这里开始

- [游戏库](https://rhythmarchive.github.io/games/) — 浏览当前收录内容
- [资源搜索](https://rhythmarchive.github.io/search/) — 跨游戏查找图片
- [意见反馈](https://rhythmarchive.github.io/feedback/) — 提交资源错误、下载问题或功能建议

## 🛠️ 本地开发

需要 **Node.js 22.12+**。

```bash
npm ci
npm run site:dev
```

完整检查：

```bash
npm run ci:check
```

构建产物预览：

```bash
npm run site:preview
```
